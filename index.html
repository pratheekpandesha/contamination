Bands smaller than the cutoff are reported as primer dimers and never counted as the product. Set 0 for very short amplicons.

Several sizes (e.g. 550, 320) are each called separately. Per-row and per-lane sizes can be set in the tables below, or in column B of the sheet (e.g. "550; 320").
